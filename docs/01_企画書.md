# サイト企画書: バンタン文化祭LP（福岡校）

前期審査会（9/19）発表課題用の企画書です。  
この4項目を読み、指示書・コンテンツ一覧・ロゴ仕様とあわせて制作を進めてください。

---

## 1. 概要

バンタン文化祭2025・**福岡校**の魅力を伝える **1枚ものランディングページ（LP）** を制作します。

- ページは **1枚だけ**（校舎別の別ページは作らない）
- 開催情報・「文化祭について」・福岡校のコンテンツは **2025年の内容** を使います
- **ロゴは過去年度のものを流用します**（`logo_2025.svg` を配布）。自分で作る必要はありません
- 使える画像は、学校提供の **キービジュアル** と **提供ロゴ（SVG）** が中心です  
  （フリー素材・AI生成画像は使えません）
- **9月19日の前期審査会** で発表します

参考サイト（見た目の丸コピーは禁止。構成や情報の出し方の参考にしてください）:  
https://www.vantan.co.jp/special/bunkasai/

## 2. 目的・ターゲット

### 目的

福岡校で開催されるバンタン文化祭の雰囲気とコンテンツを伝え、来場を検討している人に「行ってみたい」「何があるか分かった」と感じてもらうこと。

### ターゲット

|     | 想定する人                   | ページを見たあとにどうなってほしいか       |
| --- | ---------------------------- | ------------------------------------------ |
| 主  | 文化祭の来場を検討している人 | 日時・場所・雰囲気・気になる出し物が分かる |
| 副  | 保護者・入学を検討している人 | 学びの成果が発表される場だと感じる         |

## 4. デザイン方針（トンマナ）

### トーン

祭典らしい **賑わい** と、クリエイティブで **親しみやすい** 雰囲気を目指してください。  
テーマ「Unleash! 可能性の扉」と大きく矛盾しない方向で考えます。

### 使えるもの／使えないもの

| 使える                                     | 使えない                     |
| ------------------------------------------ | ---------------------------- |
| 学校提供のキービジュアル（PC用・スマホ用） | 人物が写っている写真         |
| 提供ロゴ（`logo_2025.svg`）                | フリー素材・AI生成画像       |
| CSSによる色・余白・装飾                    | 公式ロゴのトレース・無断改変 |

キービジュアルのファイル名:

- PC向け: `mv_pc.jpg`
- スマホ向け: `mv_sp.webp`

ロゴの使い方・配置ルールは、配布の **ロゴ仕様** を読んでください。

### 自由度

- **セクションの種類と順番**は上表どおり（固定）
- **色・余白・フォント・レイアウトの細部**は自分で決めてよい
- 参考サイトと同じ見た目にする必要はない

### 避けてほしいこと

- 文字が読みにくい色の組み合わせ（薄い字＋薄い背景など）
- 禁止されている画像の使用
- 情報が足りず、日時やコンテンツが分からないページ
