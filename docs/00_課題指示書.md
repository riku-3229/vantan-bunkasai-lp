# 指示書: バンタン文化祭LP制作課題

前期審査会(9/19)発表課題の指示書です。  
企画書・コンテンツ一覧・ロゴ仕様とあわせて読み、制作を進めてください。

---

## 1. ファイル構成

このフォルダ(配布フォルダ)がそのまま制作・提出のベースです。

| ファイル／フォルダ | 内容                                                                   |
| ------------------ | ---------------------------------------------------------------------- |
| `index.html`       | LP本体(`<head>`とCSS読み込みのみの最小限の雛形)                        |
| `css/style.css`    | スタイルシート(中身は空。ここに各自CSSを書く)                          |
| `images/`          | `mv_pc.jpg`・`mv_sp.webp`(配布KV)、`logo_2025.svg`(提供ロゴ)           |
| `docs/`            | 企画書・コンテンツ一覧・ロゴ仕様など、参考資料一式(提出物には含めない) |

`index.html` の `<body>` は空です。ページ構成(6セクション)は[`01_企画書.md`](./01_企画書.md)を参照し、構造(HTML)から各自マークアップしてください。

---

## 2. 技術要件

- HTML5のセマンティックな要素を使う(`header` `nav` `section` `footer` など)
- ページ内ナビ(アンカーリンク)で各セクションへジャンプできること
- PC・スマホ両方で読める見た目にする(KVは `mv_pc.jpg` / `mv_sp.webp` を使い分け)
- 原則HTML/CSSのみで制作

---

## 3. 素材ルール

| 使える                                               | 使えない                   |
| ---------------------------------------------------- | -------------------------- |
| 学校提供のキービジュアル(`mv_pc.jpg` / `mv_sp.webp`) | 人物が写っている写真       |
| 提供ロゴ(`logo_2025.svg`)                            | フリー素材・AI生成画像     |
| CSSによる色・余白・装飾                              | ロゴの改変・トレースし直し |

ロゴは過去年度のものを流用します。使い方・配置ルールは [`03_ロゴ仕様.md`](./03_ロゴ仕様.md) を参照してください。

## 5. 発表

- 9/19 前期審査会で、一人ずつ発表します

---

## 6. 評価の観点

- ページ構成(6セクションが揃っているか)
- HTML(セマンティック・ページ内ナビが機能しているか)
- CSS(トンマナ・読みやすさ・レスポンシブ)
- ロゴ(提供ロゴを改変せず、識別できる形で配置できているか)
- 素材ルールを守っているか(人物写真・フリー素材・AI生成の不使用)
- 発表(制作意図・工夫点を説明できているか)
