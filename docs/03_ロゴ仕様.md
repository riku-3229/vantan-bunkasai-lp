# ロゴ仕様: バンタン文化祭LP

このLPで使うロゴは、**過去年度(2025)のものを流用**します。Illustratorでの自作は不要です。

あわせて読む: [`01_企画書.md`](./01_企画書.md)(企画書)

---

## 1. 概要

| 項目 | 内容 |
|------|------|
| ファイル | `logo_2025.svg` |
| 提供元 | 過去年度(2025)のロゴを流用 |
| LP上の配置 | ヒーロー付近・ヘッダー/ナビ周りなど(レイアウトは各自) |

---

## 2. 使い方・ルール

- `images/logo_2025.svg` をそのまま使う。**改変・トレースし直しは不可**(色・形を変えない)
- 小さく表示しても識別できるサイズ・余白で配置する
- 背景色とのコントラストを確保し、潰れないようにする

---

## 3. HTML/CSSでの使い方(簡潔)

- `<img src="images/logo_2025.svg" alt="バンタン文化祭2025">` など、**alt にイベント名** を入れる
- サイズはCSS(`width`/`max-width`)で調整する
- (発展)インラインSVGも可能だが、本課題は `<img>` で十分

---

## 4. 提出・連携

追加の提出物はありません。配布済みの `logo_2025.svg` をそのまま使い、LP上でロゴが確認できる状態にしてください(少なくとも1箇所)。
